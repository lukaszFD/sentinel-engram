# Sentinel Engram 🧠

**Sentinel Engram** is the long-term memory of [Cyber Sentinel](https://github.com/lukaszFD/cyber-sentinel). Cyber Sentinel watches the network and judges each threat in real time; Sentinel Engram remembers what it has seen and connects it over time.

It links AI threat verdicts, home DNS activity and Pi-hole blocklists in a **Vertex Synapse** CTI graph, with a **Neo4j** view for visual analysis. The graph gives **n8n** and AI agents the context they need to spot anomalies, instead of raw logs.

*An engram is the trace a memory leaves in the brain.*
